🔒 Why Local-First Matters

Sending client data, proprietary logs, and API tokens to commercial cloud models creates irreversible compliance risks. PromptShield keeps token scrubbing and surrogate translation 100% on-device before any model ever sees it.

⚡ Zero Hallucinations on Secrets

Language models cannot reliably detect every API key format or credit card checksum. PromptShield uses deterministic regular expressions with Shannon entropy calculation to guarantee zero PII leakage.

🔄 Bi-Directional Rehydration

Surrogates like [EMAIL_1] allow open-weight models to follow reasoning steps without ever seeing the real address. Upon response, PromptShield restores the actual value locally with zero cloud involvement.
